# PvZ Farm Bot

Небольшая ферма-кликер в телеге по мотивам пвз. Сажаешь растения, ждёшь, собираешь солнышки, прокачиваешься, обгоняешь друзей в топе. Всё :D

Делал для предмета РПМ

## Что внутри

- 7 растений: от подсолнуха (1 минута, +10☀️) до гриба судьбы (6 часов, +4000☀️)
- до 9 грядок на игрока (открываются за солнышки)
- магазин семян и грядок
- ежедневный бонус (`/daily`)
- таблица лидеров
- хранение в SQLite, никаких внешних БД поднимать не надо

## Стек

- .NET 9
- [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot) 22.x
- Microsoft.Data.Sqlite

## Команды бота

| Команда | Что делает |
|---------|------------|
| `/start` | регистрация, стартовый набор: 100☀️, 3 семечка подсолнуха, 3 грядки |
| `/farm` | состояние двора: что растёт, сколько ждать |
| `/plant` | посадить семечко на свободную грядку |
| `/harvest` | собрать всё, что готово |
| `/shop` | купить семена или новую грядку |
| `/profile` | баланс, дата регистрации, занятость грядок |
| `/daily` | ежедневные +50☀️ |
| `/top` | топ игроков по балансу |
| `/help` | список команд |

## Запуск

1. Получить токен у [@BotFather](https://t.me/BotFather).
2. Положить его в `src/PvZFarmBot/appsettings.Local.json`:

```json
{
  "BotToken": "123456:ABC-DEF..."
}
```

Этот файл в `.gitignore`, чтобы случайно не закоммитить токен. Если его нет — берётся `appsettings.json`

3. Запускать:

```bash
cd src/PvZFarmBot
dotnet run
```

База `pvzfarm.db` создастся сама при первом запуске, растения тоже сидятся автоматически

## Структура

```
src/PvZFarmBot/
├── Program.cs          — точка входа, polling
├── Handlers/           — разбор апдейтов и колбэков
├── Services/           — логика фермы, магазина, юзеров
├── Models/             — User, Plant, Plot, InventoryItem
├── Data/Database.cs    — инициализация SQLite + сид растений
└── appsettings.json    — токен
```

## Заметки

- Время роста и цены захардкожены в `Database.SeedPlants()` — если хочется поменять баланс, правится там
- У большинства растений прописан `CustomEmojiId` от премиум-стикеров, без премиума будет показываться обычный эмодзи, но сейчас все криво, ибо мне был влом этим заниматься :D
- Любой стикер, отправленный боту, вернёт `FileId` и инфу — удобно при добавлении новых растений (делал для того, чтобы узнать айди эмодзи)
